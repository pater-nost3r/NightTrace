# NightTrace

**У каждого изменения есть след.** Независимый веб-инструмент для сравнения реальных снимков SPHEREx одной области неба, сделанных в разные даты. Пользователь сравнивает кадры, отмечает изменение, проверяет возможные причины и сохраняет воспроизводимую запись наблюдения.

Проект не является сайтом NASA, IPAC или миссии SPHEREx. Данные: SPHEREx Level 2 (DR1, QR3) из NASA/IPAC IRSA. Отметка в NightTrace — это наблюдение пользователя, а не подтверждённое открытие.

*English summary is at the end.*

## Что умеет

- **Сравнение:** режимы A | B (шторка), мигание с выбором скорости и паузой, разность, одиночный кадр. Разность открывается, только когда проверены все условия: полосы перекрываются, обе оценки качества L2 — Pass, астрометрия решена в обоих кадрах, остаточный сдвиг измерен надёжно (r ≥ 0,5, чёткий максимум) и не больше 0,5 пикс., общие данные есть хотя бы в половине поля. Иначе интерфейс называет невыполненные условия. Общая шкала яркости (asinh) для обоих кадров, три уровня контраста, масштаб и панорамирование.
- **Шкала времени:** все кадры области, назначение в слоты A и B, пошаговое переключение.
- **Проверка кадров:** интервал, перекрытие спектральных полос, покрытие поля, флаги качества SPHEREx, остаточный сдвиг (взаимная корреляция), версии обработки, PSF. Всё, что не проверялось (эфемериды, каталоги, фотометрия), прямо помечено «не проверено».
- **Отметки** в координатах RA/Dec (а не в пикселях экрана), четыре категории: возможное движение, изменение яркости, возможный артефакт, не уверен. Для каждой отметки показаны альтернативные объяснения.
- **Сохранение:** ссылка с версией состояния (`#o=1.…`, данные только во фрагменте URL; включает кадры, отметки, заметку, режим, контраст, масштаб и центр), экспорт и импорт JSON с проверкой, карточка наблюдения для печати. Ссылки на кадры не обрезаются: если состояние не помещается в ссылку, файл JSON всё равно сохраняется.
- **Карта неба** с настоящим фоном SPHEREx: обзор DR1 в канале 2,19 мкм, собранный из HiPS-куба IRSA (`scripts/build_skymap.py`). Только для навигации.
- **Поиск** любой точки неба через IRSA SIA, отмена поиска, повторы при ошибках архива, защита от устаревших ответов. В выбранной серии каждая пара кадров перекрывается по полосе не меньше чем на 50 %, сервер явно возвращает пару A/B. Если архив не ответил, это показывается как ошибка архива, а не «нет покрытия», и не кешируется.
- Русский и английский интерфейс, системная/светлая/тёмная тема, мобильная раскладка с нижней панелью, управление с клавиатуры, учёт `prefers-reduced-motion`.

Клавиши: `Пробел` — мигание, `←/→` — соседний кадр в активном слоте, `a`/`b` — выбор слота, `1–4` — режимы, `m`/`v` — отметка/осмотр, `+`/`−`/`0` — масштаб.

## Встроенные примеры

| Пример | Что показывает |
|---|---|
| Туманность Кошачий Глаз (NGC 6543) | 15 визитов за 17 месяцев; пара по умолчанию с перекрытием полос 58 %. |
| Ложное изменение | Кадры 29.12.2025 и 01.01.2026: туманность «ярче» в B, но полосы кадров не перекрываются (измерено), поэтому сравнивать яркость во времени нельзя. Возможная причина — линия [S III] 0,953 мкм в полосе B; спектр не измерялся, это гипотеза. |
| Один визит | Две последовательные экспозиции одного визита (обе — детектор 1). Короткий интервал и разные полосы требуют проверки; различия сами по себе не доказывают движение. |
| Туманность Ориона (M42) | Два визита с интервалом в полгода. |
| Плутон: реальное движение | Шесть кадров 25–27 апреля 2026 года. За 2,7 суток Плутон смещается на 53″ (≈9 пикс.). |

**Как проверен пример с Плутоном.** Положение Плутона для времени каждого кадра рассчитано по эфемериде JPL DE421 (пакет `de421`, геоцентрическое астрометрическое положение с учётом светового времени). SPHEREx находится примерно в 7000 км от центра Земли, поэтому видимое положение Плутона может отличаться от геоцентрического до ~0,3″ (7000 км / 5 млрд км). Для наглядного примера при пикселе 6,15″ этого достаточно, но абсолютная точность лучше угловой секунды не установлена: для неё нужно учесть положение SPHEREx, точность WCS и полный бюджет астрометрических ошибок. Кадры найдены перебором заголовков всех кадров детектора 1 за недели 2025W17–W19 и 2026W16–W18 в копии IRSA на AWS. В каждом из шести кадров яркий источник найден в 0,1–0,5″ от прогноза; его пик в 72–120 раз выше разброса фона (пик / 1,4826·MAD кадра — оценка контраста, а не полное отношение сигнал/шум). В проверенных достаточно удалённых (не ближе 3 пикс.) положениях Плутона на других датах яркого источника не найдено (контраст не больше 2,5); это не доказывает отсутствие любого сигнала. Пиксели Плутона в кадре 25 апреля конвейер SPHEREx сам пометил флагом «transient». Скрипт: `scripts/pluto_ephemeris.py`, результаты лежат в манифесте примера. Другие малые тела в этом поле не проверялись.

## Архитектура

```
server.py               Flask-приложение (переменная app) — точка входа для Vercel и локально
nighttrace/             Python: идентификаторы кадров, чтение FITS по HTTP Range, RICE, TAN-SIP WCS,
                        перепроекция на общую сетку, поиск IRSA SIA
public/                 статический интерфейс (без сборки), отдаётся CDN Vercel
public/data/examples/   подготовленные примеры (манифест + кадры NTF1)
nighttrace/budget.py    общий лимит времени одного запроса (50 с при лимите функции 60 с)
scripts/build_examples.py  подготовка примеров тем же кодом, что /api/frame
scripts/build_skymap.py    фон карты из HiPS-куба SPHEREx DR1
scripts/pluto_ephemeris.py прогноз и проверка положения Плутона (локально, нужен jplephem + de421)
tests/                  pytest (ядро и API) и node --test (интерфейс)
legacy/                 исходный проект SkyShift, в развёртывание не входит
```

API (все GET, без состояния на сервере, с заголовками кеширования):

- `/api/health`
- `/api/search?ra=&dec=&band=` — поиск кадров в IRSA SIA, отбор сопоставимых (до 6).
- `/api/observations?ra=&dec=&ids=` — описание конкретных кадров по ссылке.
- `/api/frame?id=&ra=&dec=` — вырезка 512×512 (6,15″/пикс., север вверху) в формате NTF1 (gzip, float16 + флаги). Кешируется CDN на 30 дней.

Сервер читает из FITS только нужные строки (HTTP Range к копии IRSA на AWS Open Data), поэтому один кадр — около 1–4 с и до 12 МБ трафика (локальные замеры; на медленном архиве дольше). Каждый запрос API выполняется с общим лимитом 50 с (лимит функции Vercel — 60 с). Тайм-аут каждого обращения к архиву берётся из оставшегося времени, повторы начинаются, только если время осталось. Тело ответа читается порциями по 64 КБ: перед каждой порцией проверяется срок и тайм-аут сокета уменьшается до остатка, поэтому медленно «капающий» ответ не продлевает запрос. Срок проверяется и перед тяжёлыми вычислениями (перепроекция, распаковка флагов каждые 64 строки, сетка длин волн). При исчерпании лимита приходит ответ `504 {"state":"archive_error","code":"timeout"}`. Превышение срока ограничено одной порцией чтения или одним вычислительным шагом (локально — доли секунды), что оставляет запас до 60 с; на Vercel это пока не измерялось. Изображения и FITS никогда не попадают в URL, только идентификаторы кадров.

## Локальный запуск

Нужен Python 3.12.

```
python -m venv .venv
.venv/bin/pip install -r requirements.txt     # Windows: .venv\Scripts\pip
.venv/bin/python server.py                    # http://127.0.0.1:8000
```

Тесты:

```
pip install pytest
python -m pytest -q tests
node --test tests/frontend.test.mjs           # Node 20+
```

Пересобрать примеры (сеть к AWS S3, несколько минут): `python scripts/build_examples.py`.

## Развёртывание на Vercel

1. Загрузите репозиторий на GitHub.
2. На vercel.com: **Add New → Project → Import** этого репозитория.
3. Framework Preset определится автоматически (Flask/Python). Если нет, выберите **Other**. Build Command и Output Directory оставьте пустыми, Root Directory — корень репозитория.
4. Переменные окружения не нужны. Python 3.12 берётся из `.python-version`.
5. **Deploy.** После публикации проверьте `https://<проект>.vercel.app/api/health` (ответ `{"ok": true, …}`) и откройте главную страницу.

Ошибка «Found server.py but it does not export a top-level app» исправлена: `server.py` объявляет `app = Flask(...)` на уровне модуля. Лимиты: функция до 60 с (`vercel.json`) и общий лимит запроса 50 с внутри кода; ответ `/api/frame` меньше 1 МБ (лимит 4,5 МБ). Размер зависимостей в чистом локальном окружении — около 90 МБ (лимит 500 МБ); в сборочной среде Vercel не измерялся. Папки `legacy/`, `tests/`, `scripts/` исключены из функции.

После публикации проверьте preview: главную страницу, `/api/health`, поиск любой точки, загрузку кадра и восстановление сохранённой ссылки в другой вкладке.

## Внешние сервисы и секреты

- IRSA SIA v2 (`irsa.ipac.caltech.edu`) — поиск кадров. Публичный, без ключа.
- Копия IRSA на AWS Open Data (`nasa-irsa-spherex.s3.us-east-1.amazonaws.com`) — чтение FITS. Публичная, без ключа.
- Google Fonts — шрифты IBM Plex (при недоступности используются системные).
- Только для подготовки данных локально: HiPS-куб SPHEREx DR1 в той же копии AWS и эфемерида JPL DE421 из пакета `de421` (PyPI).

Секреты и API-ключи не нужны. См. `.env.example`.

## Ограничения

- Разность — простая B − A после вычета медианного фона: PSF не выравнивается, у ярких звёзд остаются кольца.
- Для произвольных полей нет сверки с эфемеридами малых тел и каталогами переменных звёзд — в проверках это помечено «не проверено». Эфемерида есть только в примере с Плутоном.
- SPHEREx — спектральный обзор: длина волны меняется по полю кадра (LVF). Сравнение во времени корректно только при перекрытии полос, это проверяется автоматически.
- Языки кроме русского и английского — только через автоматический перевод браузера.

## English summary

NightTrace is an independent tool for comparing real SPHEREx Level 2 frames of one sky field taken on different dates. You can mark a change in RA/Dec, review the frame checks and possible explanations, and save a reproducible observation as a versioned link or a JSON file. It is not affiliated with NASA, IPAC or the SPHEREx mission. A mark is a user observation, not a confirmed discovery.

- **Run locally:** `pip install -r requirements.txt && python server.py`, then open http://127.0.0.1:8000.
- **Deploy to Vercel:** import the repository, keep the auto-detected framework (or choose Other) and leave the build settings empty. No environment variables are needed. `server.py` exports a top-level Flask `app`, and `public/` is served by the CDN.
- **Data:** IRSA SIA v2 is used for search. FITS frames are read with HTTP range requests from the IRSA AWS Open Data mirror. No keys are needed.
- **Real motion example:** Pluto in six SPHEREx frames on 25–27 April 2026, checked against the JPL DE421 ephemeris. In every frame a bright source lies 0.1–0.5″ from the geocentric prediction (sub-arcsecond absolute accuracy is not claimed: SPHEREx's orbit alone can shift Pluto by up to ~0.3″), and no bright source was found at the checked, sufficiently distant positions of other dates.
- **Limitations:** PSFs are not matched in difference mode. Arbitrary fields have no ephemeris or catalogue cross-match. The Vercel deployment has not been verified yet.
